# The writing audit

**A gate, not a review.** Every Sectors piece passes this before it is delivered, in every medium. Copy that fails a check is fixed, not excused.

It states the universal checks. A skill may add checks in its own references, layering further structural and compliance checks on top of these. No skill may drop a check stated here.

> **Reference copy.** Pulled in from the Sectors skills repo's shared `_shared/writing/audit.md` (jigsawinthecity/claudeskills) so this skill stays self-contained and needs no other repo checked out alongside it. This copy is static, not auto-synced from there — re-pull it by hand if the canonical file changes upstream.

## How to report

**Fix silently, report only survivors.** Run the pass, fix every hit yourself, and do not deliver a scorecard. The one thing you do report, in a line or two alongside the piece, is anything you could not fix and why: a check that failed because a needed number does not exist, a rule that genuinely conflicts with the format, a figure dropped for being out of band.

Two rounds maximum. If a passage still fails after two rewrites, the structure is wrong. Restructure it rather than continuing to sand the sentences.

A fix that breaks a different check is not a fix. Re-run the countable checks after rewriting.

## The countable pass

Run on the copy a reader will see. Exclude tables, code, frontmatter and appendices. Count, do not estimate.

| # | Check | Fails when |
| --- | --- | --- |
| C1 | **Fabricated numbers** | Any figure that does not trace to a real field fetched this run or a cited source, including anything computed mid-composition and never re-checked |
| C2 | **Advice** | Any instruction to buy, sell or hold; any price target framed as our call; any "this is cheap" |
| C3 | **Negative parallelism** | Any of the six banned shapes in `./core.md` section 4a: "not X, it's Y"; "it's X, not Y"; "isn't just X, it's Y"; the rhetorical question flip; "A rather than B" and "less A than B"; the "real story" family. Also any pivot word (but, actually, really, instead, the truth is, the real, the hidden) following a rejected frame |
| C4 | **Staccato runs** | Three or more consecutive sentences under about 8 words inside any one unit |
| C5 | **Parallel fragment triples** | "Fast. Cheap. Reliable." Any run of three noun or adjective fragments |
| C6 | **Multi-sentence headlines** | Any headline, heading or subject line built from two or more clipped sentences |
| C7 | **Dash connectors** | Any em dash, en dash or spaced hyphen used as a pause or connector |
| C8 | **Blocklisted vocabulary** | Any word or phrase from `./core.md` section 4c |
| C9 | **Banned metaphors** | Any family or verb from `./core.md` section 4b, including inside a skill's own analogy carve-out |
| C10 | **Hedged verbs in a hook** | looks, seems, appears, suggests, hints at, points to, may signal, in any headline, heading or subject line |
| C11 | **Orphan references** | A pronoun, demonstrative or bare abstraction in a unit whose antecedent lives in a different unit. Cover every other unit and read this one |
| C12 | **Reader instructions as openers** | "Take out", "Strip away", "Look closer", "Here's what", "What if", "Consider" opening a line that could just state the finding |
| C13 | **Bare numbers** | A figure with no comparison anchor in the same sentence or the next |
| C14 | **Source naming** | "Sectors API" or a bare "Sectors" anywhere a reader can see it, instead of `sectors.app` |
| C15 | **Tricolons** | A rule-of-three list where the honest count was two or four |
| C16 | **Sentence-opening repetition** | The same word opening more than three sentences per thousand words, ignoring "The" and "A" |
| C17 | **Empty intensifiers** | very, quite, substantial, notable, considerable, or "significant" with no figure behind it |
| C18 | **Emoji and glyphs** | Any emoji or decorative glyph. The "·" in a kicker, label or chip row is house-style chrome and is exempt |

C3, C4 and C5 are the three that catch drafts nothing else catches, because they are cadence rather than vocabulary. A piece can contain zero blocklisted words and still read as machine output.

## The read-aloud pass

Read the copy aloud, or subvocalise at speaking pace. These are audible and close to invisible on the page.

- **The drone.** Several sentences where the voice does not change pitch. Usually C4 passing on a technicality. Fix by joining two short sentences with the causal link that was already there, and attaching the number the short version left out.
- **The stall.** A sentence you have to restart. Usually a nested clause. Break it.
- **The wind-up.** Words before the point arrives.
- **The flourish.** A sentence that sounds like it wants applause. It is never the sentence carrying the finding. Cut it.
- **The borrowed voice.** A sentence that could appear in any market's coverage of any company. Replace the generic noun with the specific one.
- **The false close.** Copy that ends by telling the reader what they just read.
- **The apology.** Hedging stacked because the claim is weak. Either the evidence supports it, so state it, or it does not, so cut it.

## The rewrite move

For any passage flagged above:

1. What is this passage's single job? If it has none, delete it.
2. Which sentence carries that job? Keep it. For every other sentence, ask whether it adds a fact, a benchmark, a mechanism or a necessary transition. If not, cut it.
3. Which claim is weakest? Source it, quantify it, or remove it.
4. Rewrite at roughly two thirds the length, keeping every fact. If the shorter version says everything the original did, use it. It almost always does.

For a C4 or C5 failure specifically, the fix is never to pad. Join the clipped sentences with their real causal relationship and restore the figure that was dropped to make them short.
