# Weekly Insights v2: HTML components (blocks 4 to 8)

Exact markup for the blocks the generic chrome in `html-chrome.md` does not cover. Copy these shapes, change only the content. They match the 16 and 23 November 2026 issues and the live reference `~/Desktop/newsletter/samples/weekly-insights-v2/newsletter.html`. `{{campaign}}` is `weekly-insights-v2_<Monday date>`. Tickers are written `TICKER` here, and each one is a link in the real issue: `<a href="https://sectors.app/idx/<lower>?utm_source=newsletter&amp;utm_medium=email&amp;utm_campaign={{campaign}}&amp;utm_content=<block>&amp;utm_term=<lower>" style="color:#9E0142;font-weight:700;text-decoration:none;">TICKER</a>`.

## Rules these snippets encode

- Section heading `font-size:17px;font-weight:800;padding-bottom:4px`. Sub-labels (Beyond the week, Scheduled macro) are grey 12px, not bold headings.
- Insider Filings columns: Type centered, Shares and Stake right-aligned. Every data table has a `#fbe9d8` header row, 7px 10px cell padding, body rows 6px 10px with a `#eee` bottom border. Nothing else (no zebra, no `#e4cdb4` rules).
- Closing links are `Read more market headlines &rarr;` and `See the full dividend calendar &rarr;` in a 13px div with `padding-top:10px` or `12px`.
- The week grid is coloured cells (`#fbe9d8` day header, `#eafaf0` cells, `#f7f1e7` for an empty day showing "None"), each entry a green uppercase label, the linked ticker, then the detail in grey.
- Summary headings: **The bull read** `#568475`, **The bear read** `#D53E50`, **What to watch next** `#1c1c1c`.
- **Insider Filings shares are compact and signed**, two decimals, never the full integer: `+2.23m`, `-98.12m`, `+238.44m`, `+1.47b`. Use `m` below one billion and `b` from 1,000 million up. Stake keeps the `before% &rarr; after%` form. In markdown the arrow is `→`.
- Block 4: every finding carries one 268px published Instagram card, an italic caption ending with the Instagram credit, and three bullets. A finding with no card is cut. The card has to show that finding's own ticker or story: when the ticker itself has no post, a post on the same company's results or filing is acceptable, and a post about an unrelated name is not. Self-review counts the `<img` tags in block 4 against the number of findings and fails the issue when any finding has none.
